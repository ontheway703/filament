# 材质属性与着色模型

## 概述

Filament 实现了一个全面的基于物理的渲染 (PBR) 材质系统，支持高级材质属性和多种着色模型。本文档探讨材质属性系统、着色模型实现和高级渲染效果。

## 核心 PBR 属性

### 基础材质属性

Filament 遵循金属度-粗糙度 PBR 工作流：

```glsl
struct MaterialInputs {
    // 基础 PBR 属性
    float4 baseColor;        // 反照率 (RGB) + 不透明度 (A)
    float  roughness;        // 表面微表面粗糙度 [0,1]
    float  metallic;         // 金属/介电质混合 [0,1]
    float  reflectance;      // 介电质反射率 [0,1]，默认 0.04

    // 表面法线
    float3 normal;           // 世界空间法线向量

    // 发射
    float4 emissive;         // 自发光 (RGB) + 曝光 (A)

    // 环境遮蔽
    float  ambientOcclusion; // AO 因子 [0,1]
};
```

### 属性关系

理解 PBR 属性相互作用：

```glsl
// 金属度工作流关系
float3 diffuseColor = baseColor.rgb * (1.0 - metallic);
float3 f0 = mix(vec3(0.16 * reflectance * reflectance), baseColor.rgb, metallic);

// 粗糙度映射（感知到线性）
float alpha = roughness * roughness;

// 能量守恒
float3 kS = fresnelSchlick(cosTheta, f0);  // 镜面反射贡献
float3 kD = (1.0 - kS) * (1.0 - metallic); // 漫反射贡献
```

## 高级材质属性

### 清漆层

汽车油漆和塑料材质：

```glsl
// 清漆层属性
float  clearCoat;            // 清漆层强度 [0,1]
float  clearCoatRoughness;   // 清漆层表面粗糙度 [0,1]
float3 clearCoatNormal;      // 清漆层法线（可选）

// 在材质函数中的实现
void material(inout MaterialInputs material) {
    material.clearCoat = materialParams.clearCoat;
    material.clearCoatRoughness = materialParams.clearCoatRoughness;

    // 清漆层的可选单独法线贴图
    if (materialParams_clearCoatNormalMap != 0u) {
        material.clearCoatNormal = texture(materialParams_clearCoatNormalMap, getUV0()).xyz * 2.0 - 1.0;
    }
}
```

### 光泽

织物和天鹅绒类材质：

```glsl
// 织物材质的光泽属性
float3 sheenColor;       // 光泽色调颜色
float  sheenRoughness;   // 光泽粗糙度 [0,1]

// 典型织物材质设置
void material(inout MaterialInputs material) {
    material.baseColor = float4(0.1, 0.1, 0.2, 1.0);  // 深色基底
    material.roughness = 0.9;                          // 非常粗糙
    material.metallic = 0.0;                           // 非金属

    // 织物外观的光泽
    material.sheenColor = float3(0.8, 0.8, 1.0);      // 蓝白色光泽
    material.sheenRoughness = 0.3;
}
```

### 各向异性

拉丝金属和毛发类材质：

```glsl
// 各向异性反射
float anisotropy;        // 各向异性强度 [-1,1]
float3 anisotropyDirection; // 各向异性方向（切线空间）

// 拉丝金属示例
void material(inout MaterialInputs material) {
    material.baseColor = float4(0.9, 0.9, 0.9, 1.0);
    material.roughness = 0.1;
    material.metallic = 1.0;

    // 沿拉丝方向的各向异性反射
    material.anisotropy = 0.8;
    // 方向来自切线空间或纹理
    material.anisotropyDirection = normalize(getWorldTangent());
}
```

### 次表面散射

具有光线穿透的有机材质：

```glsl
// 次表面属性
float3 subsurfaceColor;  // 次表面散射颜色
float  subsurfacePower;  // 散射衰减 [0.1, 20+]
float  thickness;        // 材质厚度 [0,1]

// 皮肤材质示例
void material(inout MaterialInputs material) {
    material.baseColor = float4(0.8, 0.6, 0.5, 1.0);
    material.roughness = 0.4;
    material.metallic = 0.0;

    // 皮肤的次表面散射
    material.subsurfaceColor = float3(0.9, 0.3, 0.2);  // 红色底色
    material.subsurfacePower = 12.234;                  // 典型皮肤值
    material.thickness = 0.5;
}
```

## 着色模型

### Lit 着色模型

标准基于物理的光照：

```glsl
material {
    shadingModel : lit,
    // ... 其他属性
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        // 将应用完整的 PBR 光照计算
        material.baseColor = materialParams.baseColor;
        material.roughness = materialParams.roughness;
        material.metallic = materialParams.metallic;
    }
}
```

Lit 着色实现：
- **漫反射 BRDF**：Lambert 或 Disney 漫反射
- **镜面反射 BRDF**：GGX/Trowbridge-Reitz 分布
- **菲涅尔**：Schlick 近似
- **几何衰减**：Smith G 函数
- **多重散射补偿**：能量守恒 BRDF

### Unlit 着色模型

无光照计算，适用于 UI 和特效：

```glsl
material {
    shadingModel : unlit,
    vertexDomain : device  // 常用于后处理
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        // 只使用 baseColor 和 emissive
        material.baseColor = texture(materialParams_colorMap, getUV0());
        material.emissive = float4(0.0); // 无额外发射
    }
}
```

### Subsurface 着色模型

半透明材质的专门光照：

```glsl
material {
    shadingModel : subsurface,
    blendingMode : transparent,  // 通常需要透明度
    twoSidedLighting : true      // 双面光照
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        material.baseColor = materialParams.baseColor;
        material.roughness = materialParams.roughness;

        // 次表面属性
        material.subsurfaceColor = materialParams.subsurfaceColor;
        material.subsurfacePower = materialParams.subsurfacePower;
        material.thickness = materialParams.thickness;
    }
}
```

### Cloth 着色模型

针对织物材质优化：

```glsl
material {
    shadingModel : cloth,
    // 织物材质通常使用这些设置
    specularAntiAliasing : true,
    clearCoatIor : 1.5
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        material.baseColor = materialParams.baseColor;
        material.roughness = materialParams.roughness;

        // 光泽对织物特别重要
        material.sheenColor = materialParams.sheenColor;
        material.sheenRoughness = materialParams.sheenRoughness;

        // 织物纤维的次表面散射
        material.subsurfaceColor = materialParams.subsurfaceColor;
    }
}
```

## 透明度和混合

### 混合模式

Filament 支持多种透明度模式：

```glsl
material {
    blendingMode : transparent,    // Alpha 混合
    // 或
    blendingMode : fade,          // 抖动透明度
    // 或
    blendingMode : masked,        // Alpha 测试
    maskThreshold : 0.5           // Alpha 测试阈值
}
```

### 透明度模式实现

```glsl
enum class TransparencyMode : uint8_t {
    DEFAULT,                      // 正常混合
    TWO_PASSES_ONE_SIDE,         // 两遍渲染
    TWO_PASSES_TWO_SIDES         // 分别前后面渲染
};

// 双遍透明材质
material {
    blendingMode : transparent,
    transparencyMode : twoPassesOneSide,
    depthWrite : false,          // 禁用深度写入
    depthFunc : lessEqual        // 深度测试模式
}
```

### Alpha Coverage

植被和纹理的抗锯齿 alpha 测试：

```glsl
material {
    blendingMode : masked,
    alphaToCoverage : true,      // 硬件 alpha-to-coverage
    maskThreshold : 0.5,
    multisampleAntiAliasing : true
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        float4 albedo = texture(materialParams_albedoMap, getUV0());
        material.baseColor = albedo;

        // Alpha 测试自动处理
    }
}
```

## 高级渲染效果

### 折射

透明材质的实时折射：

```glsl
material {
    blendingMode : transparent,
    refractionMode : cubemap,     // 或 screenSpace
    refractionType : solid,       // 或 thin
    ior : 1.5                     // 折射率
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        material.baseColor = float4(0.9, 0.95, 1.0, 0.1);  // 着色玻璃
        material.roughness = 0.0;                           // 光滑表面
        material.transmission = 1.0;                        // 完全透射
    }
}
```

### 反射

环境映射和屏幕空间反射：

```glsl
material {
    reflectionMode : screenSpace,  // 实时 SSR
    // 或
    reflectionMode : cubemap      // 环境映射
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        material.baseColor = float4(0.1, 0.1, 0.1, 1.0);
        material.roughness = 0.05;    // 镜面般
        material.metallic = 1.0;      // 金属表面
        material.reflectance = 1.0;   // 最大反射率
    }
}
```

### 法线贴图

通过法线贴图实现表面细节：

```glsl
fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        // 采样法线贴图
        float3 normalSample = texture(materialParams_normalMap, getUV0()).xyz;

        // 从 [0,1] 转换到 [-1,1]
        float3 normal = normalSample * 2.0 - 1.0;

        // 转换到世界空间（由 Filament 自动处理）
        material.normal = normal;
    }
}
```

## 性能优化

### 材质属性成本

理解相对性能成本：

```
性能成本（相对）：
├── baseColor       : 1x（最小）
├── roughness       : 1x（最小）
├── metallic        : 1x（最小）
├── normal          : 2x（纹理查找 + 变换）
├── emissive        : 1x（如果为零则最小）
├── clearCoat       : 3x（额外 BRDF 计算）
├── sheen           : 2x（织物 BRDF）
├── anisotropy      : 2x（各向异性 BRDF）
├── subsurface      : 4x（额外光照通道）
└── refraction      : 5x（屏幕空间或立方体贴图查找）
```

### 优化策略

```glsl
// 对静态属性使用常量
material {
    constants : [
        { name : HAS_NORMAL_MAP, value : true },
        { name : USE_CLEAR_COAT, value : false }
    ]
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);

        material.baseColor = materialParams.baseColor;

        // 条件编译消除未使用的分支
        #if HAS_NORMAL_MAP
            material.normal = texture(materialParams_normalMap, getUV0()).xyz * 2.0 - 1.0;
        #endif

        #if USE_CLEAR_COAT
            material.clearCoat = materialParams.clearCoat;
        #endif
    }
}
```
