# Filament Android 构建系统与工具链

## 概述

Filament Android 使用现代化的构建系统，结合 Gradle 和 CMake 来管理 Java/Kotlin 代码和原生 C++ 代码的编译。本文档详细介绍构建系统的架构、配置和使用方法。

## 构建系统架构

### 整体架构
```
Filament Android 构建系统
├── Gradle (Android 构建系统)
│   ├── AAR 模块管理
│   ├── 依赖管理
│   └── 发布配置
├── CMake (原生代码构建)
│   ├── 跨平台构建配置
│   ├── 原生库编译
│   └── JNI 绑定
└── NDK (原生开发工具包)
    ├── 编译器工具链
    ├── 平台库
    └── 调试工具
```

### 核心组件

#### 1. Gradle 构建配置
主要的 `build.gradle` 文件位于各个模块目录中：

```gradle
// android/filament-android/build.gradle
android {
    compileSdkVersion 34
    buildToolsVersion "34.0.0"
    ndkVersion "27.0.11718014"

    defaultConfig {
        minSdkVersion 21
        targetSdkVersion 34
        versionCode 1
        versionName "1.0"

        externalNativeBuild {
            cmake {
                cppFlags "-std=c++17"
                arguments "-DANDROID_STL=c++_shared",
                         "-DANDROID_SUPPORT_FLEXIBLE_PAGE_SIZES=ON"
            }
        }

        ndk {
            abiFilters "arm64-v8a", "armeabi-v7a", "x86_64", "x86"
        }
    }

    externalNativeBuild {
        cmake {
            path "CMakeLists.txt"
            version "3.22.1"
        }
    }
}
```

#### 2. CMake 配置
每个模块的 `CMakeLists.txt` 定义了原生库的构建规则：

```cmake
# android/filament-android/CMakeLists.txt
cmake_minimum_required(VERSION 3.19)
project(filament-jni)

set(CMAKE_CXX_STANDARD 17)

# 查找 Filament 库
find_library(filament-lib filament)
find_library(backend-lib backend)
find_library(utils-lib utils)

# 定义 JNI 库
add_library(filament-jni SHARED
    src/main/cpp/Engine.cpp
    src/main/cpp/Fence.cpp
    src/main/cpp/Filament.cpp
    src/main/cpp/IndexBuffer.cpp
    src/main/cpp/Material.cpp
    src/main/cpp/MaterialInstance.cpp
    # ... 更多源文件
)

# 链接库
target_link_libraries(filament-jni
    ${filament-lib}
    ${backend-lib}
    ${utils-lib}
    android
    log
    EGL
    GLESv3
)
```

## NDK 工具链配置

### 版本要求
- **NDK 版本**: 27.0.11718014 (推荐)
- **最低支持**: NDK 25.1.0+
- **CMake 版本**: 3.22.1+
- **编译器**: Clang 17.0+

### 支持的 ABI
```bash
# 支持的架构
arm64-v8a     # 64位 ARM (主要目标)
armeabi-v7a   # 32位 ARM (向后兼容)
x86_64        # 64位 x86 (模拟器)
x86           # 32位 x86 (模拟器)
```

### 编译器标志
```cmake
# C++ 标准
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 优化标志
set(CMAKE_CXX_FLAGS_RELEASE "-O3 -DNDEBUG -fvisibility=hidden")
set(CMAKE_CXX_FLAGS_DEBUG "-O0 -g -DDEBUG")

# Android 特定标志
set(CMAKE_CXX_FLAGS "${CMAKE_CXX_FLAGS} -fno-rtti -fno-exceptions")
```

## 模块化构建

### AAR 模块结构
Filament Android 采用模块化设计，每个功能组件都是独立的 AAR：

```
android/
├── filament-android/          # 核心渲染引擎
├── filamat-android/           # 材质编译器
├── gltfio-android/            # glTF 加载器
├── filament-utils-android/    # 通用工具
└── common/                    # 共享 JNI 工具
```

### 依赖关系
```gradle
// 模块依赖关系
dependencies {
    // filament-android (核心)
    implementation project(':filament-android')

    // 可选模块
    implementation project(':filamat-android')   // 材质编译
    implementation project(':gltfio-android')    // glTF 支持
    implementation project(':filament-utils-android') // 工具库
}
```

## 构建脚本详解

### 主构建脚本
项目根目录的 `build.sh` 脚本支持 Android 构建：

```bash
#!/bin/bash

# Android 构建
./build.sh -p android release

# 构建参数说明
# -p android: 指定 Android 平台
# release: 构建类型 (debug/release)
# -c: 清理构建
# -i: 安装到本地
```

```bash

# 运行测试
./gradlew test

# 发布到本地仓库
./gradlew publishToMavenLocal

# 清理构建
./gradlew clean
```

## 原生库构建流程

### 1. 预构建检查
```bash
# 检查 NDK 环境
if [ -z "$ANDROID_HOME" ]; then
    echo "Error: ANDROID_HOME not set"
    exit 1
fi

if [ -z "$ANDROID_NDK_HOME" ]; then
    export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.0.11718014"
fi
```

### 2. CMake 配置阶段
```bash
# 配置 CMake 构建
cmake -DCMAKE_TOOLCHAIN_FILE=$ANDROID_NDK_HOME/build/cmake/android.toolchain.cmake \
      -DANDROID_ABI=arm64-v8a \
      -DANDROID_PLATFORM=android-21 \
      -DCMAKE_BUILD_TYPE=Release \
      -DANDROID_STL=c++_shared \
      ..
```

### 3. 编译阶段
```bash
# 并行编译
cmake --build . --parallel $(nproc)

# 安装到指定目录
cmake --install . --prefix ./install
```

## 常见构建问题与解决方案

### 1. NDK 版本不匹配
**问题**: CMake 找不到 NDK 或版本不兼容
```bash
# 解决方案: 设置正确的 NDK 路径
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.0.11718014"
export PATH="$ANDROID_NDK_HOME:$PATH"
```

### 2. ABI 架构问题
**问题**: 在某些设备上找不到原生库
```gradle
android {
    defaultConfig {
        ndk {
            // 确保包含目标设备的 ABI
            abiFilters "arm64-v8a", "armeabi-v7a"
        }
    }
}
```

### 3. 内存不足
**问题**: 构建过程中内存不足
```gradle
// gradle.properties
org.gradle.jvmargs=-Xmx4g -XX:MaxPermSize=512m
org.gradle.parallel=true
org.gradle.configureondemand=true
```

### 4. 符号链接问题
**问题**: Windows 上符号链接处理
```bash
# 启用符号链接支持
git config core.symlinks true
```

## 性能优化建议

### 1. 构建性能
```gradle
// gradle.properties
org.gradle.parallel=true
org.gradle.caching=true
org.gradle.configureondemand=true

android.enableBuildCache=true
android.useAndroidX=true
```

### 2. 原生库优化
```cmake
# 启用链接时优化 (LTO)
set(CMAKE_CXX_FLAGS_RELEASE "${CMAKE_CXX_FLAGS_RELEASE} -flto")
set(CMAKE_SHARED_LINKER_FLAGS_RELEASE "${CMAKE_SHARED_LINKER_FLAGS_RELEASE} -flto")

# 符号隐藏
set(CMAKE_CXX_VISIBILITY_PRESET hidden)
set(CMAKE_VISIBILITY_INLINES_HIDDEN YES)
```

### 3. 包大小优化
```gradle
android {
    buildTypes {
        release {
            shrinkResources true
            minifyEnabled true
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'),
                         'proguard-rules.pro'
        }
    }
}
```
