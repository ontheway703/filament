# Filament iOS 示例应用详解

## 示例应用概览

Filament 提供了 8 个精心设计的 iOS 示例应用，展示了从基础渲染到高级特性的完整使用案例。

```
示例应用架构:
基础入门 → 材质系统 → 模型加载 → 高级特性
    ↓         ↓         ↓          ↓
hello-     hello-    hello-    hello-ar
triangle   pbr       gltf      gltf-viewer
```

## 1. hello-triangle - 基础三角形渲染

**位置**: `ios/samples/hello-triangle/`
**难度**: ⭐
**学习目标**: Filament 基础 API 和渲染循环

### 核心功能

#### 基础几何体创建
```objc
// FilamentView.mm - 三角形顶点数据
struct Vertex {
    filament::math::float2 position;
    uint32_t color;
};

static const Vertex TRIANGLE_VERTICES[3] = {
    {{1, 0}, 0xffff0000u},                              // 红色
    {{cos(M_PI * 2 / 3), sin(M_PI * 2 / 3)}, 0xff00ff00u}, // 绿色
    {{cos(M_PI * 4 / 3), sin(M_PI * 4 / 3)}, 0xff0000ffu}, // 蓝色
};

static constexpr uint16_t TRIANGLE_INDICES[3] = { 0, 1, 2 };
```

#### 顶点缓冲区设置
```objc
- (void)setupVertexBuffer {
    // 创建顶点缓冲区
    app.vb = VertexBuffer::Builder()
        .vertexCount(3)
        .bufferCount(1)
        .attribute(VertexAttribute::POSITION, 0, VertexBuffer::AttributeType::FLOAT2, 0, 12)
        .attribute(VertexAttribute::COLOR, 0, VertexBuffer::AttributeType::UBYTE4, 8, 12)
        .normalized(VertexAttribute::COLOR)
        .build(*engine);

    // 上传顶点数据
    app.vb->setBufferAt(*engine, 0,
        VertexBuffer::BufferDescriptor(TRIANGLE_VERTICES, 36, nullptr));
}
```

#### 材质和着色器
```objc
// 使用预编译的着色器
static constexpr uint8_t BAKED_COLOR_PACKAGE[] = {
#include "bakedColor.inc"  // 通过 matc 编译生成
};

- (void)setupMaterial {
    app.mat = Material::Builder()
        .package(BAKED_COLOR_PACKAGE, sizeof(BAKED_COLOR_PACKAGE))
        .build(*engine);
}
```

#### 渲染循环
```objc
- (void)render {
    if (renderer->beginFrame(swapChain)) {
        // 清除颜色和深度缓冲区
        renderer->render(filaView);
        renderer->endFrame();
    }
}
```

### 学习要点
- Filament 引擎初始化流程
- 顶点缓冲区和索引缓冲区管理
- 材质系统基础
- 渲染循环实现

## 3. hello-gltf - glTF 模型加载

**位置**: `ios/samples/hello-gltf/`
**难度**: ⭐⭐⭐
**学习目标**: 3D 模型加载和资产管道

### 核心功能

#### glTF 资产加载
```objc
#include <gltfio/Animator.h>
#include <gltfio/FilamentAsset.h>
#include <gltfio/AssetLoader.h>

- (void)loadGltfModel {
    // 创建 glTF 加载器
    gltfio::AssetLoader* assetLoader = gltfio::AssetLoader::create({
        .engine = engine,
        .materials = gltfio::createJitShaderProvider(engine)
    });

    // 加载模型数据
    NSData* modelData = [NSData dataWithContentsOfFile:
        [[NSBundle mainBundle] pathForResource:@"DamagedHelmet" ofType:@"glb"]];

    // 创建资产实例
    gltfio::FilamentAsset* asset = assetLoader->createAsset(
        (const uint8_t*)modelData.bytes, modelData.length);

    if (asset) {
        // 将模型添加到场景
        asset->releaseSourceData();
        scene->addEntities(asset->getEntities(), asset->getEntityCount());

        // 设置相机焦点
        gltfio::Aabb bounds = asset->getBoundingBox();
        [self setupCameraForBounds:bounds];
    }
}
```

#### 纹理和材质处理
```objc
- (void)processTextures:(gltfio::FilamentAsset*)asset {
    // 获取资产中的纹理
    const auto& textures = asset->getTextures();

    for (size_t i = 0; i < textures.size(); ++i) {
        Texture* texture = textures[i];
        if (texture) {
            // 异步加载纹理数据
            [self loadTextureAsync:texture index:i];
        }
    }
}
```

#### 动画系统
```objc
- (void)setupAnimation:(gltfio::FilamentAsset*)asset {
    gltfio::Animator* animator = asset->getAnimator();
    if (animator && animator->getAnimationCount() > 0) {
        // 播放第一个动画
        animator->applyAnimation(0, 0.0f);

        // 设置动画循环
        app.animator = animator;
        app.animationDuration = animator->getAnimationDuration(0);
        app.currentTime = 0.0f;
    }
}

- (void)updateAnimation:(float)deltaTime {
    if (app.animator) {
        app.currentTime += deltaTime;
        if (app.currentTime > app.animationDuration) {
            app.currentTime = 0.0f;  // 循环播放
        }

        app.animator->applyAnimation(0, app.currentTime);
        app.animator->updateBoneMatrices();
    }
}
```

### 学习要点
- glTF 2.0 格式和加载流程
- 异步资源加载和管理
- 动画系统和骨骼动画
- 相机控制和场景管理

## 4. hello-ar - ARKit 集成

**位置**: `ios/samples/hello-ar/`
**难度**: ⭐⭐⭐⭐
**学习目标**: 增强现实和外部纹理

### 核心功能

#### ARKit 会话配置
```objc
#import <ARKit/ARKit.h>

@interface FilamentArViewController : UIViewController <ARSessionDelegate>
@property (nonatomic, strong) ARSession* session;
@property (nonatomic, strong) ARConfiguration* configuration;
@end

- (void)setupAR {
    // 创建 AR 会话
    self.session = [[ARSession alloc] init];
    self.session.delegate = self;

    // 配置世界跟踪
    ARWorldTrackingConfiguration* config = [[ARWorldTrackingConfiguration alloc] init];
    config.planeDetection = ARPlaneDetectionHorizontal;
    config.lightEstimationEnabled = YES;

    // 启动 AR 会话
    [self.session runWithConfiguration:config];
}
```

#### 相机纹理集成
```objc
- (void)updateCameraTexture:(CVPixelBufferRef)pixelBuffer {
    // 将 ARKit 相机帧转换为 Filament 纹理
    if (app.cameraTexture == nullptr) {
        app.cameraTexture = Texture::Builder()
            .width(1920)
            .height(1440)
            .format(Texture::InternalFormat::RGB8)
            .usage(Texture::Usage::EXTERNAL)
            .build(*engine);
    }

    // 创建外部纹理
    Platform::ExternalTexture externalTexture;
    externalTexture.image = (__bridge void*)pixelBuffer;

    app.cameraTexture->setExternalImage(*engine, &externalTexture);
}
```

#### 平面检测和放置
```objc
- (void)session:(ARSession*)session didAddAnchors:(NSArray<ARAnchor*>*)anchors {
    for (ARAnchor* anchor in anchors) {
        if ([anchor isKindOfClass:[ARPlaneAnchor class]]) {
            ARPlaneAnchor* planeAnchor = (ARPlaneAnchor*)anchor;

            // 在检测到的平面上放置虚拟对象
            [self placeObjectOnPlane:planeAnchor];
        }
    }
}

- (void)placeObjectOnPlane:(ARPlaneAnchor*)planeAnchor {
    // 创建变换矩阵
    simd_float4x4 transform = planeAnchor.transform;
    math::mat4f filamentTransform = [self convertARKitMatrix:transform];

    // 设置对象位置
    auto& tcm = engine->getTransformManager();
    tcm.setTransform(app.renderable, filamentTransform);
}
```

### 学习要点
- ARKit 框架集成
- 外部纹理和相机图像处理
- 平面检测和世界跟踪
- AR 坐标系和变换矩阵

**学习目标**: 完整应用架构和高级特性

### 核心功能

#### 多模型管理
```objc
@interface FILModelView : UIView
@property (nonatomic, strong) NSMutableArray<NSURL*>* modelURLs;
@property (nonatomic, assign) NSUInteger currentModelIndex;
@end

- (void)loadNextModel {
    if (self.currentModelIndex < self.modelURLs.count - 1) {
        self.currentModelIndex++;
        [self loadModelAtIndex:self.currentModelIndex];
    }
}

- (void)loadModelAtIndex:(NSUInteger)index {
    NSURL* modelURL = self.modelURLs[index];
    NSData* modelData = [NSData dataWithContentsOfURL:modelURL];

    // 异步加载和处理
    dispatch_async(dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0), ^{
        [self processModelData:modelData];
    });
}
```

#### 触摸手势控制
```objc
- (void)setupGestureRecognizers {
    // 旋转手势
    UIPanGestureRecognizer* panGesture =
        [[UIPanGestureRecognizer alloc] initWithTarget:self action:@selector(handlePan:)];
    [self addGestureRecognizer:panGesture];

    // 缩放手势
    UIPinchGestureRecognizer* pinchGesture =
        [[UIPinchGestureRecognizer alloc] initWithTarget:self action:@selector(handlePinch:)];
    [self addGestureRecognizer:pinchGesture];
}

- (void)handlePan:(UIPanGestureRecognizer*)gesture {
    CGPoint translation = [gesture translationInView:self];

    // 转换为相机旋转
    float sensitivity = 0.01f;
    app.cameraRotationX += translation.y * sensitivity;
    app.cameraRotationY += translation.x * sensitivity;

    [self updateCamera];
    [gesture setTranslation:CGPointZero inView:self];
}
```

**学习目标**: 透明度和混合模式

### 核心功能

#### 透明材质配置
```objc
- (void)setupTransparentMaterial {
    // 创建透明材质
    Material* transparentMat = Material::Builder()
        .package(TRANSPARENT_PACKAGE, sizeof(TRANSPARENT_PACKAGE))
        .build(*engine);

    MaterialInstance* matInstance = transparentMat->createInstance();

    // 设置透明度参数
    matInstance->setParameter("baseColor", RgbaType::LINEAR, {1.0f, 0.2f, 0.2f, 0.7f});
    matInstance->setParameter("metallic", 0.0f);
    matInstance->setParameter("roughness", 0.4f);

    app.transparentMaterial = matInstance;
}
```

#### 渲染顺序管理
```objc
- (void)setupRenderOrder {
    // 设置透明对象的渲染优先级
    auto& rcm = engine->getRenderableManager();

    // 不透明对象优先渲染
    rcm.setLayerMask(app.opaqueRenderable, 0x1, 0x1);

    // 透明对象后渲染
    rcm.setLayerMask(app.transparentRenderable, 0x2, 0x2);
    rcm.setPriority(app.transparentRenderable, 1);  // 较低优先级
}
```

### 学习要点

## 示例应用最佳实践

### 1. 代码组织结构
```
SampleApp/
├── FilamentView/          # Filament 渲染视图
│   ├── FilamentView.h/.mm # 主渲染类
│   ├── App.h             # 应用状态结构
│   └── FilamentViewController.h/.mm  # 视图控制器
├── Resources/            # 资源文件
│   ├── *.glb            # 3D 模型
│   ├── *.ktx            # 纹理文件
│   └── *.inc            # 预编译着色器
├── SupportFiles/         # 支持文件
│   ├── main.m           # 应用入口
│   ├── AppDelegate.h/.m # 应用委托
│   └── Info.plist       # 应用配置
└── project.yml          # XcodeGen 项目描述
```

### 2. 内存管理模式
```objc
// 统一的资源清理模式
- (void)dealloc {
    // 1. 停止渲染循环
    displayLink.paused = YES;

    // 2. 清理 Filament 资源
    engine->destroy(renderer);
    engine->destroy(scene);
    engine->destroy(view);
    engine->destroy(swapChain);

    // 3. 销毁引擎
    Engine::destroy(engine);
}
```

### 3. 错误处理策略
```objc
- (BOOL)initializeFilament {
    @try {
        engine = Engine::create(Engine::Backend::METAL);
        if (!engine) {
            // 回退到 OpenGL
            engine = Engine::create(Engine::Backend::OPENGL);
        }

        if (!engine) {
            [self showError:@"Failed to create Filament engine"];
            return NO;
        }

        return YES;
    }
    @catch (NSException* exception) {
        [self showError:[NSString stringWithFormat:@"Filament error: %@", exception.reason]];
        return NO;
    }
}
```

这些示例应用为学习 Filament iOS 开发提供了完整的参考和最佳实践指导。
