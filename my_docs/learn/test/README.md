## 快速开始

要运行 Filament 的所有测试，可以使用以下命令：

```bash
# 运行所有单元测试
./build.sh -u debug

# 或者单独构建和运行测试
./build.sh debug
./build.sh test
```

## 测试类型概述

Filament 的测试体系包括以下几种类型：

1. **单元测试** - 使用 Google Test 框架，测试各个模块的核心功能
2. **后端测试** - 测试不同图形 API 后端的兼容性和正确性
3. **渲染差异测试** - 通过图像对比验证渲染结果的正确性
4. **工具测试** - 测试材质编译器、网格转换器等工具的功能
5. **集成测试** - 测试整个引擎的集成功能

## 测试框架

- **主要框架**: Google Test (gtest)
- **CMake 集成**: 每个模块都有对应的测试目标
- **CI/CD**: 通过 GitHub Actions 自动运行
- **渲染测试**: 使用 Mesa 软件渲染进行无头测试
