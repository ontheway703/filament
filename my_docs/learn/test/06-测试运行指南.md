# Filament 测试运行指南

## 快速开始

### 运行所有测试
```bash
# 构建并运行所有测试
./build.sh -u debug

# 等效的分步操作
./build.sh debug
./build.sh test
```

### 运行特定类型的测试
```bash
# 只运行单元测试
./out/cmake-debug/libs/math/test_math

# 只运行渲染差异测试
bash test/renderdiff/test.sh

# 只运行后端测试（macOS）
./out/cmake-debug/filament/backend/backend_test_mac
```

## 构建系统集成

### CMake 测试目标

#### 查看所有测试目标
```bash
# 在构建目录中查看测试目标
cd out/cmake-debug
make help | grep test

# 或者使用 ninja
ninja -t targets | grep test
```

#### 构建特定测试
```bash
# 构建单个测试
cmake --build out/cmake-debug --target test_math

# 构建所有测试
cmake --build out/cmake-debug --target all
```

### 测试发现机制

**测试列表文件**: `build/common/test_list.txt`
```bash
# 查看将要运行的测试列表
cat build/common/test_list.txt
```

**测试执行脚本**: `build.sh` 中的 `run_tests()` 函数
```bash
function run_tests {
    while read -r test; do
        run_test "${test}"
    done < build/common/test_list.txt
}
```

## 详细测试运行方法

### 1. 单元测试运行

#### 基础运行
```bash
# 运行数学库测试
./out/cmake-debug/libs/math/test_math

# 运行工具库测试
./out/cmake-debug/libs/utils/test_utils

# 运行引擎核心测试
./out/cmake-debug/filament/test/test_filament
```

#### 使用 gtest 过滤器
```bash
# 运行特定的测试用例
./out/cmake-debug/libs/math/test_math --gtest_filter="VecTest.*"

# 排除特定测试
./out/cmake-debug/filament/test/test_filament \
    --gtest_filter="-FilamentTest.FroxelData"

# 列出所有测试用例（不运行）
./out/cmake-debug/libs/math/test_math --gtest_list_tests
```

#### 详细输出和报告
```bash
# 生成 XML 报告
./out/cmake-debug/libs/math/test_math \
    --gtest_output="xml:test_results.xml"

# 详细输出
./out/cmake-debug/libs/math/test_math --gtest_verbose

# 重复运行检测不稳定测试
./out/cmake-debug/libs/math/test_math --gtest_repeat=10
```

### 2. 后端测试运行

#### 平台特定运行

**macOS (Metal/OpenGL)**:
```bash
# Metal 后端测试
./out/cmake-debug/filament/backend/backend_test_mac

# 指定后端
FILAMENT_BACKEND=metal ./out/cmake-debug/filament/backend/backend_test_mac
FILAMENT_BACKEND=opengl ./out/cmake-debug/filament/backend/backend_test_mac
```

**Linux (OpenGL/Vulkan)**:
```bash
# OpenGL 后端测试
./out/cmake-debug/filament/backend/backend_test_linux

# Vulkan 后端测试（需要 Vulkan 驱动）
VK_DRIVER_FILES=/usr/share/vulkan/icd.d/intel_icd.x86_64.json \
    ./out/cmake-debug/filament/backend/backend_test_linux
```

#### 环境变量配置
```bash
# 强制软件渲染
export LIBGL_ALWAYS_SOFTWARE=1
export GALLIUM_DRIVER=llvmpipe

# Vulkan 调试
export VK_LAYER_PATH=/usr/share/vulkan/explicit_layer.d
export VK_INSTANCE_LAYERS=VK_LAYER_KHRONOS_validation

# Metal 调试（macOS）
export MTL_SHADER_VALIDATION=1
export MTL_DEBUG_LAYER=1
```

### 3. 渲染差异测试运行

#### 完整渲染差异测试
```bash
# 运行完整的渲染差异测试流程
bash test/renderdiff/test.sh
```

#### 分步执行
```bash
# 第一步：生成渲染图像
bash test/renderdiff/generate.sh

# 第二步：获取黄金图像
python3 test/renderdiff/src/golden_manager.py \
    --branch=main \
    --output=out/golden/

# 第三步：执行对比
python3 test/renderdiff/src/compare.py \
    --golden=out/golden/ \
    --test=out/renderdiff/
```

#### 单个测试执行
```bash
# 运行特定的渲染测试
python3 test/renderdiff/render.py \
    --test test/renderdiff/test/material_test.json \
    --output out/renderdiff/

# 查看测试描述
cat test/renderdiff/test/material_test.json
```

#### 环境配置
```bash
# 设置 Mesa 软件渲染
source test/renderdiff/src/preamble.sh
start_

# 获取测试资产
git clone https://github.com/google/filament-assets.git gltf

# Python 依赖
pip install tifffile numpy pillow
```

## 调试和问题诊断

### 1. 测试失败调试

#### 使用调试器
```bash
# GDB 调试
gdb --args ./out/cmake-debug/libs/math/test_math --gtest_filter="FailingTest.*"
(gdb) run
(gdb) bt  # 查看堆栈

# LLDB 调试（macOS）
lldb ./out/cmake-debug/libs/math/test_math
(lldb) run --gtest_filter="FailingTest.*"
(lldb) bt
```

#### 详细日志
```bash
# 启用详细日志
export FILAMENT_LOG_LEVEL=DEBUG
./out/cmake-debug/filament/test/test_filament

# 后端调试日志
export FILAMENT_BACKEND_DEBUG=1
./out/cmake-debug/filament/backend/backend_test_mac
```

### 2. 渲染差异调试

#### 查看差异图像
```bash
# 测试失败时会生成差异图像

open out/renderdiff/material_test_diff.png  # macOS
```

```bash
# 在 compare.py 中修改容差
python3 test/renderdiff/src/compare.py \
    --tolerance=0.02 \
    --golden=out/golden/ \
    --test=out/renderdiff/
```

## 最佳实践

### 1. 开发工作流

#### 代码变更前
```bash
# 运行相关测试
./build.sh test

# 特定模块测试
./out/cmake-debug/libs/math/test_math  # 修改 math 库后
```

#### 提交前检查
```bash
# 完整测试套件
./build.sh -u debug

# 渲染差异测试
bash test/renderdiff/test.sh

# 代码格式检查
find . -name "*.cpp" -o -name "*.h" | xargs clang-format -i
```

### 2. 测试编写

#### 添加新测试
```cmake
# 在模块的 CMakeLists.txt 中添加
set(TEST_SRCS ${TEST_SRCS} tests/test_new_feature.cpp)
```

#### 测试文件模板
```cpp
#include <gtest/gtest.h>
#include "YourHeader.h"

class YourFeatureTest : public ::testing::Test {
protected:
    void SetUp() override {
        // 初始化测试数据
    }

    void TearDown() override {
        // 清理资源
    }
};

TEST_F(YourFeatureTest, BasicFunctionality) {
    // 测试基础功能
    EXPECT_TRUE(true);
}
```

### 3. 性能考虑

#### 测试隔离
- 每个测试应该是独立的
- 不要依赖测试执行顺序
- 清理测试创建的资源

#### 并行执行
```bash
# 并行运行测试（如果支持）
./out/cmake-debug/libs/math/test_math --gtest_jobs=4
```
