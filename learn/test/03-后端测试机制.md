# Filament 后端测试机制

## 后端测试架构

Filament 的后端测试验证不同图形 API 的实现正确性，确保跨平台兼容性。

## 支持的图形后端

### 1. OpenGL/OpenGL ES
- **桌面**: OpenGL 4.1+
- **移动**: OpenGL ES 3.0+
- **Web**: WebGL 2.0

### 2. Vulkan
- **桌面**: Vulkan 1.0+
- **移动**: Android Vulkan

### 3. Metal
- **macOS**: Metal 2.0+
- **iOS**: Metal 2.0+

### 4. WebGPU
- **实验性**: Dawn WebGPU 实现

```cpp
TEST_F(BackendTest, ComputeShaderBasic) {
    if (!driver->isFeatureSupported(Feature::COMPUTE)) {
        GTEST_SKIP() << "Compute shaders not supported";
    }

    // 创建计算着色器程序
    auto program = createComputeProgram(R"(
        #version 450
        layout(local_size_x = 1) in;

        layout(binding = 0, std430) restrict writeonly buffer OutputBuffer {
            float data[];
        };

        void main() {
            uint index = gl_GlobalInvocationID.x;
            data[index] = float(index) * 2.0;
        }
    )");

    // 创建存储缓冲区
    auto ssbo = driver->createBufferObject(
        256 * sizeof(float),
        BufferObjectBinding::SHADER_STORAGE,
        BufferUsage::DYNAMIC
    );

    // 分发计算作业
    getDriverApi().useProgram(program);
    getDriverApi().bindBufferRange(
        BufferObjectBinding::SHADER_STORAGE, 0, ssbo, 0, 256 * sizeof(float)
    );
    getDriverApi().dispatchCompute(256, 1, 1);

    executeCommands();

    // 读取结果并验证
    verifyComputeResults(ssbo);
}
```

### 图像对比算法
```cpp
bool ImageExpectations::compareImages(
    const LinearImage& expected,
    const LinearImage& actual,
    float threshold = 0.01f) {

    if (expected.getWidth() != actual.getWidth() ||
        expected.getHeight() != actual.getHeight()) {
        return false;
    }

    size_t diffPixels = 0;
    const auto* expectedData = expected.getPixelRef();
    const auto* actualData = actual.getPixelRef();

    for (size_t i = 0; i < expected.getPixelCount(); ++i) {
        float3 expectedRGB = expectedData[i].toLinear<float3>();
        float3 actualRGB = actualData[i].toLinear<float3>();

        float diff = length(expectedRGB - actualRGB);
        if (diff > threshold) {
            diffPixels++;
        }
    }

    // 允许少量像素差异
    float diffRatio = static_cast<float>(diffPixels) / expected.getPixelCount();
    return diffRatio < 0.05f; // 5% 容错率
}
```

## 平台特定测试配置

### CMake 配置

```cmake
# filament/backend/CMakeLists.txt
if (APPLE AND NOT IOS)
    add_executable(backend_test_mac test/mac_runner.mm ${BACKEND_TEST_SRC})
    target_link_libraries(backend_test_mac PRIVATE
        backend
        gtest
        "-framework Cocoa"
        "-framework QuartzCore"
        "-framework Metal"
    )
endif()

if (LINUX)
    add_executable(backend_test_linux test/linux_runner.cpp ${BACKEND_TEST_SRC})

        backend

        ${X11_LIBRARIES}
        ${CMAKE_DL_LIBS}
```

## 常见测试场景

### 1. 状态管理测试
- 渲染状态切换
- 资源绑定验证
- 管线状态缓存

### 2. 资源生命周期测试
- 对象创建/销毁
- 内存泄漏检测
- 资源重用

### 3. 错误处理测试
- 无效参数处理
- 资源耗尽情况
- API 调用顺序验证

### 4. 性能回归测试
- 渲染性能基准
- 内存使用监控
- 启动时间测试

这个后端测试机制确保了 Filament 在不同图形 API 和平台上的一致性和稳定性。
